## `ls ./featured-projects`

These are some of the systems and experiments I've been engineering.

### 01. SentinelAI

**AI-Powered Security-Aware CI/CD Platform**

An intelligent development security platform connecting repository analysis, AI-assisted code review, security assessment and automated remediation.

- End-to-end orchestration across multiple services.
- AI-assisted analysis, risk assessment and remediation.
- GitHub automation involving branches, commits and pull requests.
- Structured evidence logging and provider fallback.

`React` `Spring Boot` `FastAPI` `PostgreSQL` `Neo4j`

### 02. QuantCopilot AI

**Quantitative Market Intelligence Platform**

An AI-powered market intelligence platform combining technical indicators, machine learning and automated market reporting.

- Analyses 42 financial assets across multiple market categories.
- Developed Bull / Bear / High Volatility market-regime classification.
- Automated market intelligence reporting using N8N and Gemini.
- Built a full-stack dashboard backed by PostgreSQL and FastAPI.
- Handles 117K+ price records, 117K+ indicator records and 235K+ regime records.

`Python` `FastAPI` `React` `PostgreSQL` `Machine Learning` `N8N`

### 03. TrustFed

**Decentralized Financial Fraud Intelligence**

Exploring privacy-preserving collaborative fraud detection across financial datasets.

- Federated learning architecture.
- Secure aggregation and differential privacy exploration.
- ONNX Runtime FP16 inference.
- Explainable AI using TreeSHAP.
- Reached the final round of ENIGMA 5.0 – GENESIS.

`Federated Learning` `ONNX Runtime` `TreeSHAP` `Python`

### 04. Geospatial AI/ML — Urban Heat Prediction

**Machine Learning for Environmental Intelligence**

A geospatial ML system investigating urban heat patterns and predicting Landsat land-surface temperature.

- Constructed a 46-factor geospatial dataset.
- Google Earth Engine-based data engineering.
- Regional model development and comparison.
- XGBoost and LightGBM experimentation.

`Python` `Google Earth Engine` `XGBoost` `LightGBM`

### 05. Rocket Landing Optimization

**Reinforcement Learning for Autonomous Landing**

An experimental reinforcement learning pipeline for autonomous landing behaviour.

- Gymnasium LunarLander-v3 environment.
- Reward shaping and episode-based training.
- Trajectory and landing outcome analysis.
- Stable-Baselines3 and PyTorch experimentation.

`Python` `PyTorch` `Gymnasium` `Stable-Baselines3`

### 06. Allen Brain Atlas — ML Neuroscience Research

**Investigating Regional Vulnerability Across Brain Diseases**

Exploring gene-expression patterns and selective regional vulnerability associated with neurological diseases.

- Allen Human Brain Atlas exploration.
- Parkinson's, Alzheimer's and Huntington's disease research.
- Gene-expression scoring across brain regions.
- Neuroscience data analysis and visualization.

`Python` `Machine Learning` `Neuroscience` `Data Analysis`
